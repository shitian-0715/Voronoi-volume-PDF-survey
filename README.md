# Reproducibility package for Voronoi-cell volume PDFs

This repository provides the MATLAB code, numerical data, reproduced figures, and published IEEE Access article for work on normalized Poisson--Voronoi typical-cell area and volume probability density functions (PDFs).

## Repository layout

```text
.
|-- manuscript/                 # Published IEEE Access article
|-- src/matlab/                 # MATLAB reproduction and simulation code
|-- data/                       # Canonical empirical samples (Git LFS)
|-- figures/reproduced/         # PDF and EPS figures generated by the scripts
|-- README.md
`-- .gitattributes
```

The article is available at `manuscript/IEEE_Access_2026_Voronoi-Delaunay_Typical-Cell_Volume-Distributions.pdf`.

## Requirements

- MATLAB R2025a (tested version).
- Statistics and Machine Learning Toolbox for `poissrnd` when regenerating samples.
- Optimization Toolbox only for re-estimating fitted parameters with `solve_abc.m`.
- Git LFS, because the supplied `.mat` data files are LFS-managed.

## Reproduce the figures

1. Clone the repository and fetch its LFS data:

   ```bash
   git lfs pull
   ```

2. In MATLAB, run the primary script from the repository root:

   ```matlab
   run('src/matlab/main_MX.m')
   ```

3. The script reads `data/valid_areas.mat` and `data/valid_volumes.mat` and writes the 2-D and 3-D PDF figures to `figures/reproduced/`.

`src/matlab/main.m` provides the full plotting configuration, including tail plots; `src/matlab/main_v2.m` provides an alternate plotting configuration.

## Code and data

- `src/matlab/main_MX.m`, `main.m`, and `main_v2.m`: figure-reproduction scripts.
- `src/matlab/areas.m` and `volumes.m`: one realization of Poisson--Voronoi area and volume samples.
- `src/matlab/get_area_volume.m`: simulation driver for regenerating samples.
- `src/matlab/P1.m`, `P2.m`, and `P3.m`: analytical PDF models.
- `data/valid_areas.mat`: 40,002,672 empirical 2-D cell-area samples.
- `data/valid_volumes.mat`: 32,005,269 empirical 3-D cell-volume samples.

The empirical samples are normalized by the theoretical Poisson--Voronoi mean, `1/lambda`. The supplied data use `lambda = 1`, so the stored values are already unit-mean normalized.

## Optional sample regeneration

The supplied data are the canonical samples used for the figures, so regeneration is normally unnecessary. To produce a fresh realization, seed MATLAB and run:

```matlab
rng(2025, 'twister');
run('src/matlab/get_area_volume.m')
```

The 3-D simulation constructs 4,000 Voronoi tessellations and can require substantial memory and execution time. Save any regenerated data explicitly to `data/` using `-v7.3`.
